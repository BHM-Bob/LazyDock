# v0.19.0 (November 2026 - November 2026)


## 1. New Features

### 1.1 环肽拓扑修复（`prepare-lig fix-cp`）
- ✨ **多对二硫键检测与可选距离判定**  
  `_detect_disulfide_sites` 不再要求链内恰好 2 个含 SG 残基，而是按距离/成键逐对配对，每个硫原子只归入一对，支持一条链上的多对二硫键；判据只看原子名 `SG`，因此非标准含硫残基（如 LE1 的 `SG3`）也能被识别。 (`feat(lazydock/scripts/prepare_lig.py: fix-cp): 优化环肽拓扑修复`)
- ✨ **结构化的修复结果类型**  
  新增 `BackboneSite`、`DisulfideSite` 两个 `TypedDict` 与 `FixResult` 数据类，`_parse_pdb` / `_fix_backbone` / `_fix_disulfide` / `_fix_one` 的返回值与参数均补全类型注解，修复流程的状态传递取代了原先的 `_last_fixed_chains` / `_last_fixed_case` 实例属性。 (`feat(lazydock/scripts/prepare_lig.py: fix-cp): 优化环肽拓扑修复`)

### 1.2 `cif2pdb` CONECT 去重
- ✨ **`--keep-duplicate-conect` 与 `_dedup_conect`**  
  `prepare-lig cif2pdb` 默认重写 PyMOL 生成的 CONECT 块：去除重复邻居、合并同一原子的多行记录、只保留一个尾部 `END`；新增 `--keep-duplicate-conect` 可保留 PyMOL 原始写法，处理时会打印被移除的重复邻居数量。 (`feat(lazydock/scripts/prepare_lig.py: cif2pdb): 添加去重CONECT块功能及对应参数`)

### 1.3 OpenMM 弛豫（`opmm relax` / `lazydock/opmm/relax.py`）
- ✨ **backbone 闭合语义重命名**  
  `cyclic_chains` 系列参数统一改名为 `backbone_chains`，明确其语义是"头尾肽键闭合"；头尾键的平衡键长与力常数改为模块常量 `BACKBONE_BOND_LEN` / `BACKBONE_BOND_STIFFNESS`，不再通过构造函数传入。 (`refactor(lazydock/opmm/relax.py): 将头尾环肽支持重命名为 backbone 闭合并优化相关逻辑`)
- ✨ **头尾肽键 CONECT 补写**  
  新增 `_ensure_backbone_conect`：当环肽首尾均为标准残基时，`PDBFile.writeFooter` 不会写出该肽键，导致下游按 CONECT 建系读成线性肽；现按写出的 serial 补一条 `CONECT`，并跳过已有记录以避免重复邻居。 (`refactor(lazydock/opmm/relax.py): 将头尾环肽支持重命名为 backbone 闭合并优化相关逻辑`)
- ✨ **拓扑重复键去重**  
  新增 `_dedup_bonds`，删除 PDBFixer 重建拓扑时因异质原子键恢复循环产生的重复 bond 对象，修复写出 PDB 出现 `CONECT 1 261 261`（被读作双键）的问题。 (`refactor(lazydock/opmm/relax.py): 将头尾环肽支持重命名为 backbone 闭合并优化相关逻辑`)
- ✨ **二硫键氢原子名统一配置**  
  新增 `SULFUR_HYDROGEN_NAMES = ('HG', 'HG1', 'HG3')`，`_remove_disulfide_hydrogens` 按该配置删除参与二硫键的巯基氢，覆盖标准 CYS 与 LE1（青霉胺）等非标准含硫残基。 (`fix(lazydock/opmm/relax.py): 修复非标含硫残基二硫键氢删除逻辑；补充类和方法的文档说明`)
- ✨ **`opmm relax` 并行池按 GPU 动态设置**  
  进程池大小改为 `GPU 数 × --n-task-per-gpu`，GPU 槽位展开不再使用 `max(1, ...)` 兜底；未指定 `--gpus` 时回退为 `[0]`，显式传入的设备列表按用户值使用，任务分配与 `--gpus` / `--n-task-per-gpu` 保持一致。 (`refactor(lazydock/scripts/opmm.py: relax): 移除无用参数并优化并行任务分配`)

### 1.4 GROMACS 分析（`ana-gmx`）
- ✨ **RRCS 强制重算**  
  `ana-gmx RRCS` 新增 `-F/--force`，用于忽略已有结果并强制重新计算 RRCS。 (`feat(lazydock/scripts/ana_gmx.py: RRCS: add force recalculate option`)
- ✨ **相互作用热图时间轴支持纳秒单位**  
  `ana-gmx interaction` 新增 `--frames-per-ns`（默认 100），热图 y 轴的帧索引会换算为纳秒刻度显示（`Time (ns)`）。 (`feat(lazydock/scripts/ana_gmx.py): 为热图y轴添加时间单位转换支持 1. 新增--frames-per-ns命令行参数，用于设置每纳秒的帧数 2. 修改y轴刻度生成逻辑，将帧索引转换为纳秒单位显示`)

### 1.5 相互作用结果附带原子信息
- ✨ **`get_atom_level_interactions` 返回原子名与索引**  
  每条相互作用的受体端与配体端残基信息由 `(num, name, chain)` 扩展为 `(num, name, chain, atom_name, atom_idx)`，便于直接定位参与作用的原子。 (`refactor(lazydock/pml/plip_interaction.py: get_atom_level_interactions): 添加原子信息到相互作用结果中`)

## 2. Improvements and Optimizations

### 2.1 任务池与并发
- 🔄 **`ana-gmx interaction` 绘图任务不再污染结果收集**  
  `calculate_interactions` 改为预先收集帧任务名列表，结果按该列表回查，避免与绘图任务共享进程池时任务键被覆盖或串扰。 (`refactor(lazydock/scripts/ana_gmx.py: interaction: calculate_interactions): 使用任务名称列表追踪池任务`)
- 🔄 **绘图任务加入进程池后等待空闲**  
  `interaction` 在提交绘图任务后调用 `wait_till_free`，并在清空任务池后再提交绘图任务，防止任务队列过载、进度不准以及绘图任务大量堆积未被执行的极端情况。 (`refactor(lazydock/scripts/ana_gmx.py: interaction: run): 在绘图任务加入进程池后添加等待任务池空闲的逻辑...`)
- 🔄 **`run-gmx` 任务管理器初始化独立**  
  `simple_protein` 将任务管理器初始化从 `main_process` 提取为 `init_task_managers`，简化主流程。 (`refactor(lazydock/scripts/run_gmx.py: simple_protein): 提取任务管理器初始化到独立方法`)

### 2.2 逻辑与健壮性
- 🔄 **配体链判定改用已确定的受体端**  
  `get_atom_level_interactions` 通过 `res_res` 直接推导 `lig_res`，不再重复判断配体链；修复受体与配体同链（小分子内部相互作用）时错误返回单边残基信息的问题。 (`refactor(lazydock/pml/plip_interaction.py: get_atom_level_interactions): 重构配体残基链的判断逻辑...`)
- 🔄 **PLIP 模式参数校验**  
  `run_plip_analysis` 在分析前调用 `check_support_mode` 校验 `mode`，非法值会立即报错而不是静默走默认分支。 (`refactor(lazydock/pml/plip_interaction.py: run_plip_analysis): 添加检查支持模式的调用`)
- 🔄 **二硫键统一走 CHARMM36 DISU patch**  
  `createSystem` 恒使用 `ignoreExternalBonds=False`，二硫键不再手动添加 `CustomBondForce`，改由 DISU patch 提供真实键/角/二面参数；同时移除冗余的 `_add_disulfide_bond_force` 与相关构造参数。 (`refactor(lazydock/opmm/relax.py): 将头尾环肽支持重命名为 backbone 闭合并优化相关逻辑`)

## 5. Compatibility Notes

### 5.1 Breaking Changes
- 🔥 **`opmm relax --cyclic-chains` 改名为 `--backbone-chains`**  
  命令行参数与 `ForceFieldMinimizer` 构造参数同步改名；脚本或 Python 调用中的 `cyclic_chains` 需替换为 `backbone_chains`。 (`refactor(lazydock/scripts/opmm.py): rename cyclic_chains to backbone_chains and update help text`)
- 🔥 **`ForceFieldMinimizer` 移除旧构造参数**  
  `cyclic_bond_len`、`cyclic_bond_stiffness`、`ss_bond_len`、`ss_bond_stiffness` 不再接受；头尾键参数改为模块常量，二硫键键参数由力场 DISU patch 提供，另新增 `ss_max_dist`（单位 nm）。 (`refactor(lazydock/opmm/relax.py): 将头尾环肽支持重命名为 backbone 闭合并优化相关逻辑`)
- 🔥 **`get_atom_level_interactions` 返回结构变化**  
  每个残基端由 3 元组变为 5 元组（新增 `atom_name`、`atom_idx`），按位置解包的调用方需要同步修改。 (`refactor(lazydock/pml/plip_interaction.py: get_atom_level_interactions): 添加原子信息到相互作用结果中`)

### 5.2 Default Value Changes
- ⚠️ **`fix-cp --ss-max-dist` 默认关闭距离判定**  
  默认值由 `3.5`（Å）改为 `None`：默认只把 CONECT 中已存在的 SG-SG 视为二硫键，距离配对交由 OpenMM/PDBFixer（固定 0.3 nm）；仅当结构含 OpenMM 不识别的非标含硫残基或 S-S 距离超过 0.3 nm 时，才需要显式指定该值。 (`feat(lazydock/scripts/prepare_lig.py: fix-cp): 优化环肽拓扑修复`)
- ⚠️ **`fix-cp` 的 `auto` 模式优先 backbone**  
  同一结构同时含头尾闭合与二硫键时，现在先执行 backbone 修复，再把二硫键链传给 relax；此前 `auto` 会优先判为 disulfide 并跳过 OXT 删除与首尾肽键补写。 (`feat(lazydock/scripts/prepare_lig.py: fix-cp): 优化环肽拓扑修复`)
- ⚠️ **`cif2pdb` 默认重写 CONECT**  
  未指定 `--keep-duplicate-conect` 时，输出 PDB 的 CONECT 块会被去重并重整格式。 (`feat(lazydock/scripts/prepare_lig.py: cif2pdb): 添加去重CONECT块功能及对应参数`)
- ⚠️ **`opmm relax` 未指定 `--gpus` 时的默认设备**  
  未指定 `--gpus` 时进程池与 GPU 槽位按 GPU 0 展开，不再走 `device_index=None` 的默认卡路径；显式传入 `--gpus` 时以用户值为准。 (`refactor(lazydock/scripts/opmm.py: relax): 移除无用参数并优化并行任务分配`)

### 5.3 Removed Options
- 🔥 **`opmm relax --n-workers/-nw` 移除**  
  并行度改由 `--gpus` 与 `--n-task-per-gpu` 推导，脚本中传入该参数会报未识别参数错误。 (`refactor(lazydock/scripts/opmm.py: relax): 移除无用参数并优化并行任务分配`)
- 🔥 **`run-gmx simple_protein --monopolize-em` 移除**  
  能量最小化的批量互斥运行逻辑一并删除，批量任务中的 EM 现在始终按常规任务调度。 (`refactor(lazydock/scripts/run_gmx.py): 移除能量最小化独占运行逻辑`)
