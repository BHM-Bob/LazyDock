# v0.16.0 (May 2026 - September 2026)


## 1. New Features

### 1.1 AMBER Molecular Dynamics Simulation
- ✨ **AMBER MD Run Pipeline**  
  Added `run_amber.py` implementing the standard 5-step AMBER molecular dynamics simulation workflow, supporting batch tasks and resume-from-breakpoint. (`add(lazydock/scripts): 新增Amber模拟相关脚本 - run_amber.py`, `add(lazydock/scripts): 新增Amber模拟相关脚本`)
- ✨ **AMBER System Preparation**  
  Added `prepare_amber.py` for protein/ligand/complex AMBER system preparation, covering the full pdb4amber, antechamber, and tleap pipeline. (`add(lazydock/scripts): 新增Amber模拟相关脚本`)
- ✨ **MD Progress Monitoring**  
  Added mdinfo file parsing to extract simulation steps, temperature, and pressure; added a progress monitoring thread using tqdm to display real-time progress and performance. Renamed `simple_protein` to `simple_md` to extend support to ligand/complex systems. (`feat(lazydock/scripts/run_amber.py): 新增MD模拟进度监控与代码重构`)
- ✨ **GaMD Accelerated Simulation**  
  Added the `gamd_md` sub-command implementing two-phase GaMD simulation, with `parse_gamd_log` for boost parameter parsing and automatic GaMD progress monitoring. (`feat(lazydock/scripts/run_amber.py): 新增gamd_md命令与GaMD模拟支持`)
- ✨ **AMBER Analysis & Reweighting**  
  Added `ana_amber.py` analysis script and `gamd_reweight.py` algorithm module for GaMD trajectory analysis and reweighting. (`add lazydock/algorithm/gamd_reweight.py`, `add lazydock/scripts/ana_amber.py`)
- 🐛 **AMBER Executable Lookup**  
  During AMBER script development, improved `_find_executable` to prioritize the current Python/Conda environment path, then AmberTools and AMBERHOME, using `shutil.which`. (`fix(lazydock/scripts/prepare_amber.py: AmberCommand:_find_executable): 改进Amber可执行文件查找逻辑`)

### 1.2 GPU Acceleration and Scheduling
- ✨ **CUDA Trajectory Alignment**  
  Added `md_ana_cuda.py` with the `trjalign` class for MD trajectory alignment based on a specified chain, featuring CUDA-accelerated rotation matrix computation, batch processing, multi-chain selection, and frame-range filtering. (`add(lazydock/scripts/md_ana_cuda.py): 新增CUDA加速的轨迹对齐脚本`)
- ✨ **Multi-GPU Parallel Scheduling**  
  Added multi-GPU parallel scheduling and batch task management in `simple_protein`, with new `gpus`, `n-task-per-gpu`, and `monopolize-em` arguments, GPU task allocation, and mdrun GPU parameter configuration. (`feat(lazydock/scripts/run_gmx.py: simple_protein): 新增多GPU并行调度与批量任务管理功能`)
- ✨ **GPU ID Parameter for Gromcas**  
  Added an optional `gpu_ids` parameter to the `Gromcas.cls` constructor, defaulting to `[0]`. (`feat(lazydock/gmx/run.py: Gromcas: __init__): add gpu_ids parameter to constructor`)

### 1.3 OpenMM Relaxation and Structure Preparation
- ✨ **Specified-Chain Relaxation**  
  Added the `--relax-chain` argument to `relax.cls` to specify which chains to relax, automatically restraining the remaining chains to all non-relaxed chains. (`feat(lazydock/scripts/opmm.py: relax: add relax-chain argument support`)
- ✨ **Cyclic Peptide Relaxation**  
  Added `--cyclic-chains` support in `relax`, implementing cyclic chain sewing and bond restraint logic in `ForceFieldMinimizer`. (`feat(opmm,scripts): add cyclic peptide relaxation support`)
- ✨ **Disulfide Bond & Device Selection**  
  Added disulfide bond handling for specified chains including SG-SG pair auto-detection, and CUDA device index selection in `ForceFieldMinimizer`. (`feat(opmm/relax: ForceFieldMinimizer): add disulfide bond support and device index option`)
- ✨ **Disulfide Protection & GPU Scheduling in CLI**  
  Added `--disulfide-chains`, `--gpus`, and `--n-task-per-gpu` arguments to `opmm.py relax` with multi-GPU parallel task allocation. (`feat(lazydock/scripts/opmm.py): 新增二硫键保护、GPU调度支持`)
- ✨ **Cyclic Peptide Topology Fixing**  
  Added the `fix_cp` command to detect and remove extra OXT atoms from AlphaFold3-generated cyclic peptides and auto-complete terminal peptide bonds, with optional OpenMM relaxation integration. (`feat(lazydock/scripts/prepare_lig.py: fix_cp): add cyclic peptide topology fixing tool`)
- ✨ **Ligand Disulfide Repair & Outlier Removal**  
  Extended `prepare_lig.py` with `--case` (`disulfide`/`auto`), `--ss-max-dist`, `--remove-outlier-atoms`, and `--outlier-dist` arguments for disulfide ring repair and outlier atom cleanup. (`feat(lazydock/scripts/prepare_lig.py): 扩展配体预处理功能，支持二硫键修复与离群原子清理`)
- ✨ **Structure Checking Tool**  
  Added `check_structure.py` based on OpenBabel for PDB structure validation (atom clash and covalent bond-length error detection), supporting batch processing, chain filtering, and JSON output. (`feat(lazydock/scripts): add check_structure script and register it`)
- ✨ **File Type & Exact-Match Filtering**  
  Added `--file-type` and `--file-name-exact-match` arguments to `check_structure.py` for precise input file matching. (`feat(lazydock/scripts/check_structure.py): 新增文件类型匹配和精确文件名匹配功能`)
- 🐛 **AllBonds Constraint Support**  
  During cyclic/disulfide relaxation development, added mapping of `constraints='all'` to `openmm_app.AllBonds` with updated CLI option and help text. (`fix(lazydock/scripts/opmm.py: relax: add all constraints option): 支持AllBonds约束模式`)
- 🐛 **PRO Terminal Hydrogen Deletion**  
  During cyclic peptide support development, distinguished PRO vs other residues for N-terminal hydrogen deletion and fixed cyclic-PRO terminal hydrogen removal in `ForceFieldMinimizer`. (`fix(laZydock/opmm/relax.py:ForceFieldMinimizer): 优化端基氢原子删除逻辑`)
