# v0.18.0 (October 2026 - November 2026)


## 1. New Features

### 1.1 Docking Module Reconstruction (`lazydock/dock`)
- ✨ **New `lazydock/dock` Subpackage**  
  Added a dedicated docking subpackage re-constructed from `pml/adfr` and `pml/meeko_utils`: `adfr.py` (ADFRsuite preparation, gpf/autogrid, pdbqt helpers), `meeko_utils.py` (meeko-based receptor/ligand preparation), `dock_vina.py` (Vina rigid/flex docking and rescoring), `dock_adgpu.py` (AutoDock-GPU rigid/flex docking), `flex_utils.py` (flexible-residue parsing, selection and complex assembly) and `config.py` (shared constants). (`add lazydock.dock sub-module, re-construct from pml/adfr and pml/meeko_utils`)
- ✨ **meeko-based Receptor and Ligand Preparation**  
  Added `prepare_receptor_with_meeko`, `prepare_receptor_with_flexres`, `prepare_flex_docking_setup`, `prepare_ligand_with_meeko` and the related helpers, supporting rigid/flexible receptor splitting, macrocycle detection, glue-atom stripping and meeko version probing. (`feat(lazydock/pml/meeko_utils.py): 添加基于meeko的受体和配体制备工具函数`)
- ✨ **Selectable Preparation Backend (`--prepare-backend`)**  
  Added `--prepare-backend {meeko,adfr}` to `redock`, `redock-gpu` and `ana-interaction vina-score`, selecting which toolkit writes the pdbqt files handed to the engine. On the flexible paths the receptor is always split by meeko (ADT cannot produce a rigid part + flexible sidechains pair), so the switch then only selects the ligand backend. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`, `feat(lazydock/scripts/ana_interaction.py: vina_score): 添加准备后端选项`)
- ✨ **Macrocycle (Cyclic Peptide) Docking**  
  Added `--macrocycle` / `--max-ring-size` to every redock subcommand, which makes meeko cut one bond of a large ring open and attach glue pseudo-atoms so the ring conformation can adapt during the search. Supported by Vina (>= 1.2 linear attraction potential) and by AutoDock-GPU (its own glue term, no grid change required). (`feat(dock/dock_adgpu.py): 为AutoDock-GPU对接添加大环参数支持及搜索参数配置`, `refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)
- ✨ **Ring Closure Measurement**  
  Added `measure_ring_closure` / `inspect_macrocycle` and a `closure` column in the redock summary, reporting the largest glue-pair distance (angstrom) per pose, with a warning when it exceeds the closed-ring threshold. (`feat(lazydock/dock/meeko_utils.py): 添加测量环闭合距离的函数`)
- ✨ **Ring Closure Configuration**  
  Added ring-closure bookkeeping constants to `lazydock/dock/config.py`: `RING_CLOSURE_BOND_WINDOW` (covalent-neighbour vs. glue-restraint C-C window) and `RING_CLOSURE_CLOSED_A` (closed-ring cut-off), together with the preparation-backend and macrocycle defaults. (`feat(lazydock/dock/config.py): 添加环闭合相关的配置参数`)
- ✨ **AutoDock-GPU Search Control Parameters**  
  Added `--heuristics`, `--ngen` and `--autostop` to `redock-gpu` / `redock-flex-gpu`, so the evaluation budget can be made exact (`--heuristics 0`) and AutoStop can actually take effect. (`feat(dock/dock_adgpu.py): 为AutoDock-GPU对接添加大环参数支持及搜索参数配置`)
- ✨ **Shared `--spacing` and Vina Search Parameters**  
  `redock` now exposes `--spacing`, `--seed`, `--max-evals`, `--min-rmsd` and `--cpu`; `redock-gpu` accepts `--spacing` with an up-front check that rejects non-default values on the AutoDock-GPU paths, where the spacing is fixed at 0.375 A by the gpf. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)

### 1.2 Flexible Receptor Docking
- ✨ **Flexible AutoDock-GPU Subcommand**  
  Added `redock-flex-gpu`, which splits the receptor by meeko into a rigid part (used for the affinity maps) and flexible sidechains (passed via `--flexres`), so both the ligand and the selected sidechains are sampled. The grid box is computed from the ligand and then expanded to enclose every flexible residue. (`feat(lazydock/scripts/dock.py): 新增柔性对接功能, 支持 AutoDock-GPU 和 VINA 的柔性残基对接`, `feat(lazydock/scripts/dock.py): 添加redock-flex-gpu和redock-flex-vina的映射项`)
- ✨ **Flexible Mode in `redock`**  
  `redock` now serves both rigid and flexible Vina docking: giving any of `-fr` / `-fd` / `-fi` switches the receptor to a meeko rigid/flex split and dispatches to `perform_vina_flex_dock`, otherwise the rigid path runs. The former `redock-flex-vina` class was merged into `redock`. (`refactor(lazydock/scripts/dock.py): 合并 redock_flex_vina 到 redock 类，支持灵活与刚性模式切换`)
- ✨ **Three Combined Flexible-Residue Selection Sources**  
  Added `-fr/--flex-residues` (explicit `<chain>:<resnum>` or `<chain>:<RESN><resnum>` lists), `-fd/--flex-distance` (residues within a distance of any ligand heavy atom) and `-fi/--flex-interaction` (residues interacting with the ligand by fplip, with `--flex-interaction-mode` / `--flex-interaction-cutoff`). The three sources are merged and duplicated residues deduplicated. (`feat(lazydock/scripts/dock.py): 新增柔性对接功能, 支持 AutoDock-GPU 和 VINA 的柔性残基对接`)
- ✨ **Flexible Complex PDB Assembly**  
  Added `build_flex_complex_pdbstr`, which merges the rigid receptor with each pose's own flexible sidechain conformation and strips the sidechain atoms from the receptor part, so the written PDB contains the rigid receptor, the flexible sidechains and the ligand without dangling hydrogens. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)

### 1.3 GROMACS
- ✨ **Configurable `gmx` Call Name**  
  `Gromacs` now accepts `call_name=None` and resolves it from the `LAZYDOCK_GMX` environment variable first, then from the new `gmx` entry in `GlobalConfig.named_paths`, and falls back to `gmx`. (`feat(lazydock/gmx/run.py: Gromacs: __init__): 添加从环境变量和配置文件获取gmx调用名的逻辑`, `feat(lazydock/config.py): 添加gmx配置项`)
- ✨ **Per-Residue / Per-Atom RMSF Switch**  
  Added `--rmsf-atom` to `ana-gmx simple`, which switches the RMSF calculation from the default per-residue mode to per-atom. (`feat(lazydock/scripts/ana_gmx.py: simple): 添加按残基计算RMSF的选项`)

### 1.4 Runtime Custom Non-standard Amino Acid Templates
- ✨ **`CustomResidues` Module**  
  Added `lazydock/opmm/custom_residues.py`, which loads OpenMM force-field XML templates (plus an optional same-named YAML describing `atom_rename` and `resname_alias`) from any path at runtime, so new non-standard residues can be supported without touching the code. (`feat(lazydock/opmm/custom_residues.py): 新增运行时加载自定义非标准氨基酸模板的模块`)
- ✨ **`--ncaa-xml` CLI Option**  
  Added `--ncaa-xml` to `opmm relax` and `prepare-lig fix-cp` to point at external ncAA template XML files or directories, which are propagated into the relaxation workers and appended to the loaded force-field file list. (`feat(lazydock/scripts/opmm.py): 添加自定义残基XML支持到relax任务`, `feat(lazydock/scripts/prepare_lig.py): 添加自定义非标准氨基酸模板支持`)
- ✨ **Internal Bond Completion for ncAA Residues**  
  Added `sew_ncAA_internal_bonds`, which fills in missing intra-residue heavy-atom bonds from the ncAA templates before `createSystem`, avoiding the `bonds are different` error when the upstream CIF/PDB carries no usable CONECT records. (`feat(lazydock/opmm/relax.py): 支持运行时加载自定义非标准氨基酸模板并补全内部键`)
- ✨ **Truncated Residue-Name Aliases**  
  Template registration now also registers a truncated alias (e.g. `A1A2Y` -> `A1A`) for residue names exceeding the 4-character PDB limit, so templates match either form. (`refactor(lazydock/opmm/fix_ncAA.py): 重构非标准氨基酸原子名规范化与模板注册逻辑`)

## 2. Improvements and Optimizations

### 2.1 Code Refactoring
- 🔄 **`pml/adfr` Split into the `dock` Subpackage**  
  Extracted the meeko helpers into a standalone `pml/meeko_utils.py`, removed the duplicated `FlexResidue` type and tool functions from `pml/adfr.py`, then archived and finally deleted both `pml/adfr.py` and `pml/meeko_utils.py` once the `lazydock/dock` replacement was complete. (`refactor(lazydock/pml): 拆分meeko相关工具函数至独立模块，移除adfr.py重复代码`, `remove unused sub-module`)
- 🔄 **Single Common Argument Table for Redock**  
  Consolidated the arguments shared by `redock` and `redock-gpu` into `make_common_args`, and the flexible-receptor arguments into `make_flex_args`, so the two engine families cannot drift apart; subclasses delegate instead of re-listing. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)
- 🔄 **Generic GPU Task Pool**  
  Extracted `_run_dock_pool` and generalized `perform_autodock_gpu_dock_on_slot` into `perform_dock_on_slot`, so the GPU-slot queue, task submission/collection, result handling and summary writing are shared by `redock-gpu` and `redock-flex-gpu`. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`, `feat(lazydock/scripts/dock.py): 新增柔性对接功能, 支持 AutoDock-GPU 和 VINA 的柔性残基对接`)
- 🔄 **Distance-Based Flex Selection via PyMOL**  
  `select_flex_residues_by_distance` now uses PyMOL `select ... within` instead of numpy, restricts the distance judgement to heavy atoms and reports the unit (angstrom) in its error message. (`refactor(lazydock/pml/adfr.py: select_flex_residues_by_distance): 重构柔性残基选择逻辑，使用pymol select within简化计算`)
- 🔄 **Interaction-Based Flex Selection Simplified**  
  `select_flex_residues_by_interaction` now uses the residue names returned by fplip directly; the `resname_map` indirection was unnecessary because fplip preserves the input residue numbering and names. (`refactor(lazydock/pml/adfr.py: select_flex_residues_by_interaction): 移除不必要的resname_map映射，直接使用fplip返回的残基名`)
- 🔄 **ncAA Template Collection Refactor**  
  `fix_ncAA.py` now gathers built-in and external templates through a single `_collect_templates` helper (files, residue names, atom-rename map, truncated aliases) instead of hard-coded tables, and `register_ncAA_templates` / `fix_ncAA_pdb` accept a `custom` argument. (`refactor(lazydock/opmm/fix_ncAA.py): 重构非标准氨基酸原子名规范化与模板注册逻辑`)
- 🔄 **Shared Receptor-Chain Normalization**  
  Added `normalize_receptor_chain` to `lazydock/pml/utils.py` (all chains except the ligand chain when nothing is given), now used by the docking preparation paths. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)
- 🔄 **Cleanup of Dead Docking Helpers**  
  Removed the unused `parse_vina_poses` from `pml/adfr.py`, updated the `perform_vina_flex_dock` comment to reflect the `DlgFile`-based result parsing, and adjusted the `dock.py` / `autodock_utils.py` import structure with explicit type-ignore annotations. (`refactor(lazydock/pml/adfr.py): 删除无用的parse_vina_poses函数并更新注释`, `refactor(lazydock/scripts/dock.py, lazydock/pml/autodock_utils.py): 重构导入结构并添加类型忽略注释`)

### 2.2 Behavior and Robustness Improvements
- 🔄 **Summaries Written into the Batch Directory**  
  The summary/output CSV of `rosetta relax`, `ana-interaction vina-score`, `dock redock` and `dock redock-gpu` is now written into the batch directory instead of the process working directory. (`fix(lazydock/scripts): 将CSV文件保存路径修改为批处理目录下`)
- 🔄 **vina-score Task Pool Timeout**  
  `ana-interaction vina-score` now passes a 30 s timeout to `wait_till_all_done` instead of waiting indefinitely, and imports `calc_vina_score` from its new home `lazydock.dock.dock_vina`. (`refactor(lazydock/scripts/ana_interaction.py): 迁移vina评分计算模块并添加vina-score任务池超时`)
- 🔄 **No Duplicated Negative Flags in GROMACS Commands**  
  `Gromacs.gen_command` now deletes the original kwarg key after converting a `False` value into `noKEY`, so a command can no longer receive both `-noKEY` and `-KEY False`. (`refactor(lazydock/gmx/run.py: Gromacs: gen_command): 在添加noKEY后删除值为False的kwargs键，避免重复添加参数`)
- 🔄 **Explicit Flex Support Flag**  
  Added the `IS_SUPPORT_FLEX` class attribute so `redock-gpu` never receives flex arguments, keeping the flex-mode detection and dispatch in one place (`uses_flex`). (`fix(lazydock/scripts/dock.py): 修复flex模式判断逻辑及错误提示信息`)

  `ADModel.parse_content` now treats a 4-character atom name whose first character is not a digit (such as `HD21`) as a normal two-letter element name; previously `HD21` was parsed as element `D`. (`fix(lazydock/pml/autodock_utils.py: parse_content): 修复原子名解析`)
- 🐛 **Flex Mode Detection and Error Message**  
  Fixed the flex-mode branch so `redock-gpu` automatically avoids adding flex arguments and reports the correct reason when a flex flag is rejected. (`fix(lazydock/scripts/dock.py): 修复flex模式判断逻辑及错误提示信息`)

### 3.2 GROMACS Fixes
- 🐛 **MD Completion Check**  
  `run-gmx simple_protein` previously resumed whenever `md.tpr` existed; it now checks `md.log` for `Finished mdrun`, so a completed simulation is no longer re-run and an interrupted one is still continued. (`fix(lazydock/scripts/run_gmx.py: simple_protein: perform_single_md): 修复判断已完成MD模拟文件的逻辑`)

## 5. Compatibility Notes

### 5.1 Breaking Changes
- 🔥 **`lazydock.pml.adfr` and `lazydock.pml.meeko_utils` Removed**  
  Both modules were deleted; their functionality now lives in `lazydock/dock/` (`adfr.py`, `meeko_utils.py`, `dock_vina.py`, `dock_adgpu.py`, `flex_utils.py`). Python callers must update imports, e.g. `from lazydock.pml.adfr import calc_vina_score` becomes `from lazydock.dock.dock_vina import calc_vina_score`. (`remove unused sub-module`, `refactor(lazydock/scripts/ana_interaction.py): 迁移vina评分计算模块并添加vina-score任务池超时`)

### 5.2 Default Value Changes
- ⚠️ **Default Ligand/Receptor Preparation Backend**  
  `redock`, `redock-gpu`, `redock-flex-gpu` and `ana-interaction vina-score` now default to `--prepare-backend meeko` instead of ADFRsuite/ADT. Because meeko and ADT classify a few nitrogen acceptors and polar hydrogens differently, scores are not comparable across backends: existing ADT-prepared results are only reproducible with `--prepare-backend adfr`. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)
- ⚠️ **`redock` Output Table Gains a `closure` Column**  
  The redock summary now carries `path, rel_path, energy, closure`; code that reads the summary by column position must be updated. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)
- ⚠️ **Summary/Output CSV Location**  
  `rosetta relax --summary`, `ana-interaction vina-score --output`, `dock redock`/`redock-gpu` `--summary` are now resolved relative to the batch directory rather than the current working directory. (`fix(lazydock/scripts): 将CSV文件保存路径修改为批处理目录下`)
- ⚠️ **AutoDock-GPU Rejects Non-default `--spacing`**  
  `redock-gpu` and `redock-flex-gpu` exit with an error when `--spacing` is not 0.375 A, because the spacing is taken from the gpf and cannot be forwarded; use the vina-based subcommands if another spacing is required. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)
- ⚠️ **`--macrocycle` Requires meeko**  
  Combining `--macrocycle` with `--prepare-backend adfr` is rejected, since ADT has no ring-breaking option and would silently deliver a frozen ring. (`refactor(lazydock/scripts/dock.py): 重构对接代码结构并添加大环对接支持`)
- ⚠️ **MD Resume Detection**  
  `run-gmx simple_protein` decides "already done" from `md.log` (`Finished mdrun`) instead of the presence of `md.tpr`. (`fix(lazydock/scripts/run_gmx.py: simple_protein: perform_single_md): 修复判断已完成MD模拟文件的逻辑`)
- ⚠️ **GROMACS Call Name Resolution Order**  
  `Gromacs()` now resolves its executable from `LAZYDOCK_GMX`, then `GlobalConfig.named_paths['gmx']`, then the literal `gmx`; passing `call_name` explicitly still wins. (`feat(lazydock/gmx/run.py: Gromacs: __init__): 添加从环境变量和配置文件获取gmx调用名的逻辑`)

### 5.3 Dependency Changes
- 🔥 **New Docking Dependencies**  
  `meeko` and `gemmi` are now part of the `std` group; meeko must be importable by the interpreter that runs lazydock, as all ligand/receptor preparation for the default backend now runs in-process. (`build(requirements.json): 添加meeko和gemmi依赖包`)
