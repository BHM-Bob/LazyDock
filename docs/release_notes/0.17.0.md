# v0.17.0 (September 2026 - October 2026)


## 1. New Features

### 1.1 ABFE (Absolute Binding Free Energy) Pipeline
- ✨ **ABFE Preparation Script**  
  Added `prepare_abfe.py` implementing the `prepare-abfe` command, which builds ABFE systems from `complex.pdb` (receptor chain(s) + ligand chain) into the BindFlow-compatible `input/complex/` + `input/ligand/` layout. Supports multiple receptor chains and peptide ligands, with automatic box derivation (`--solv-d-auto` / `--auto-box` / `--solv-bt`), external force-field directories via `--protein-ff`, custom FEP rlist and HMR factor. (`feat: 新增ABFE预处理和运行脚本`, `fix-code: lazydock\gmx\abfe & My_Progs/LazyDock/lazydock/scripts/prepare_abfe.py: 删除与prepare-abfe不相关的PDB修复步骤，通过引入已有的prepare_gmx代码进行蛋白类型分子自动制备，增加盒子体积优化（对齐+rlist与padding自动计算盒子）`)
- ✨ **ABFE Run Script**  
  Added `run_abfe.py` implementing the `run-abfe` command with `run`/`equil`/`fep`/`status` subcommands: equilibration → Boresch restraints → FEP windows → analysis → gather, consuming the `prepare-abfe` output. (`feat: 新增ABFE预处理和运行脚本`)
- ✨ **ABFE Engine and Analysis Modules**  
  Added the `lazydock/gmx/abfe/` subpackage migrated from BindFlow: `engine.py` (run engine), `system_builder.py`, `solvent.py` (custom water models), `boresch.py` (restraint generation via MDRestraintsGenerator), `mdp.py` + `templates.py`, `fep_analysis.py` (alchemlyb MBAR/TI), `gather_results.py` (replica statistics) and `tools.py`. (`add My_Progs/LazyDock/lazydock/gmx/abfe/__init__.py`, `feat: 新增ABFE预处理和运行脚本`)
- ✨ **ABFE Progress Reporting**  
  Added `abfe-status` (run-abfe `status`) that scans an ABFE run tree and reports per-leg (ligand/complex × vdw/coul/bonded) finished windows / total, running count and elapsed wall time, read-only. (`feat: 新增ABFE预处理和运行脚本`)
- ✨ **ABFE Static Data and MDP Templates**  
  Added bundled force-field/water-model data (`gmx_ff/Slipids_2020`, `gmx_ff/amber99sb-star-ildn`, `gmx_water_models` for amber/charmm/oplsaa) and MDP templates for ligand/complex soluble and membrane legs. (`add static files for ABFE`)
- ✨ **Multi-GPU Parallel Scheduling for ABFE**  
  Added `--gpus` multi-card parallelism for `run-abfe` and a cross-run task pool (task = case × leg × replica), with improved multi-card scheduling in the engine. (`fix-code: lazydock/scripts/run_abfe.py & lazydock/gmx/abfe/engine.py: 增加GPU多卡并行功能`, `fix-code: lazydock/gmx/abfe/engine.py: 优化多卡调度`)
- ✨ **Batch Progress Bar for prepare-abfe**  
  Added a tqdm progress bar over the batch complex file list. (`feat(lazydock/scripts/prepare_abfe.py): 添加进度条显示ABFE准备进度`)
- 🐛 **Ligand HMR Support**  
  During ABFE development, applied hydrogen mass repartition to ligand topologies to match the complex leg, preventing LINCS errors and NaN values at 4 fs timestep. (`fix(lazydock/gmx/abfe/system_builder.py): 为配体拓扑添加HMR支持以避免数值爆炸`)
- 🐛 **ABFE Directory Convention**  
  During ABFE development, changed the run output layout so replica directories are created directly inside the run directory (adapted to multiple single-complex starting points) instead of under a `ligand_name` level. (`fix-code: lazydock/gmx/abfe: 修改目录约定，适配多个单复合物起点 之前为ligand_name下有replica目录，现在改为直接在run目录内建replica目录`)
- 🐛 **Equilibration Step Count**  
  During ABFE development, fixed the equilibration step calculation to use the actually effective minimum dt, avoiding halved step counts when dt_max is 0.008. (`fix(lazydock/scripts/run_abfe.py: _RunBase): 修复平衡模拟步数计算错误`)
- 🐛 **Parallel Error Reporting Timing**  
  During ABFE development, moved the final error raise after the serial Boresch stage so all parallel tasks and follow-up steps finish before errors are reported. (`fix(lazydock/gmx/abfe/engine.py: _run_equil_parallel): 调整错误检查的时机`)
- 🐛 **Prepare-abfe Input Filename**  
  During ABFE development, used the actual input filename for complex preparation instead of a hardcoded name. (`fix(lazydock/scripts/prepare_abfe.py): use input filename for complex prep instead of hardcode`)
- 🐛 **System Builder Cleanup**  
  During ABFE development, removed membrane support and redundant code, organized the `--solv-d-auto`/`--auto-box` arguments with conflict errors and a matching rlist default for `--auto-box`. (`fix-code: lazydock/gmx/abfe/system_builder.py: 删除膜支持和其他冗余代码，整理--solv-d-auto和--auto-box参数，添加冲突报错并为--auto-box配套rlist默认值`)

### 3.2 OpenMM and Structure Preparation Fixes
- 🐛 **pdb2gmx Water Model Prompt Mismatch**  
  During ABFE development, skipped the `None` fallback of the water-model expect block when `-water` is explicitly passed to pdb2gmx: otherwise the fallback mis-matched the subsequent start-terminus list, selecting a neutral NH2 N-terminus instead of charged NH3+ (system charge bias). (`fix-code: lazydock\gmx\abfe & My_Progs/LazyDock/lazydock/scripts/prepare_abfe.py: 删除与prepare-abfe不相关的PDB修复步骤，通过引入已有的prepare_gmx代码进行蛋白类型分子自动制备，增加盒子体积优化（对齐+rlist与padding自动计算盒子）`)
- 🐛 **CUDA Fork Deadlock in opmm**  
  Switched multiprocessing start method to `spawn` to avoid CUDA Runtime deadlock when forking from a CUDA-loaded parent, adapting to the mbapy_lite TaskPool argument forwarding. (`fix(lazydock/scripts/opmm.py): 修复 CUDA 子进程死锁问题`)
- 🐛 **CUDA Fork Deadlock in prepare-lig**  
  Same `spawn` switch for `prepare_lig.py` to avoid CUDA deadlock when forking from a pymol/CUDA-loaded parent (mbapy_lite TaskPool cannot pass a context argument). (`refactor(lazydock/scripts/prepare_lig.py): 修改 multiprocessing 启动方式避免 CUDA 死锁`)
- 🐛 **Relax Failure Guard**  
  `_relax_one` now raises when relaxation returns an empty structure, and `_fix_cyclic_or_disulfide_bridge` collects failed relax tasks and exits instead of silently using pre-relax structures. (`fix(lazydock/scripts/prepare_lig.py): 处理relax任务失败的情况并添加空结构检查`)
- 🐛 **LE1 Bond Angle Parameters**  
  Added the missing CA-CB/CB-SG3 bond and angle parameters for LE1 (avoiding bond breaking from LJ repulsion during minimize) and fixed the CB atom types of the LE1SS disulfide patch. (`fix(lazydock/storage/opmm/charmm36_nc_aa.xml): 补充LE1残基缺失的键角参数及LE1SS二硫补丁的原子类型修正`)
- 🐛 **Capping and N-Methyl Amino Acid Hydrogenation**  
  Added ACE/NH2 and SAR/MLE handling with `charmm36_caps.xml`, forcing custom hydrogenated templates for ACE (removed from PDBFixer built-ins) and extending the registered residue range. (`fix(lazydock/opmm/fix_ncAA.py): 修复封端残基和N-甲基氨基酸补氢问题`)
